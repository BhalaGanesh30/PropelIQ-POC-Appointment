# User Story - US_036

## Story ID
* ID: US_036

## Story Title
* Daily Schedule Calendar with Drag-and-Drop

## Description
* As a staff member, I want a daily schedule calendar view with drag-and-drop rearrangement and print-friendly rendering so that I can plan and adjust the day's appointments visually.

## Acceptance Criteria
1. **Given** I am authenticated as a staff member, **When** I open the daily schedule view, **Then** all appointments for the selected date are displayed in a time-grid calendar layout sorted by appointment time.
2. **Given** the daily schedule is displayed, **When** I drag an appointment block to a different time slot, **Then** the appointment is rescheduled to the new time, the override reason dialog is shown, and the change is reflected in the queue immediately.
3. **Given** I click "Print," **When** the print action is invoked, **Then** a print-optimized layout renders with all appointments, patient names, appointment types, and durations formatted for A4/Letter paper.
4. **Given** I select a different date using the calendar date picker, **When** the date changes, **Then** the schedule view updates to show appointments for the selected date within 1 second.

## Edge Cases
* What happens if a drag-and-drop action results in a time conflict? (System highlights the conflict and cancels the drop; a conflict resolution dialog is offered.)
* How does the system handle a day with no appointments? (The calendar renders the empty time-grid with a message: "No appointments scheduled for this date.")
