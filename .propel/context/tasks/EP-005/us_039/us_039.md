# User Story - US_039

## Story ID
* ID: US_039

## Story Title
* Insurance Verification Report and Export

## Description
* As a staff member, I want an insurance verification report with status filters and export capability so that I can review patients whose insurance requires follow-up before billing.

## Acceptance Criteria
1. **Given** I am authenticated as a staff member, **When** I navigate to the insurance verification report, **Then** all patient insurance records are displayed with their validation status (SoftValidated, ValidationFailed, ValidationPending).
2. **Given** the verification report is displayed, **When** I apply a status filter (e.g., ValidationFailed), **Then** only records matching the selected status are shown within 500 ms.
3. **Given** I filter the report, **When** I click "Export PDF," **Then** the filtered records export as a PDF within 5 seconds with patient name, insurance provider, policy number, and validation status.
4. **Given** I click "Export CSV," **When** the export is processed, **Then** a CSV file downloads with the same data fields suitable for import into a billing system.

## Edge Cases
* What happens if the report contains thousands of records? (Server-side pagination is applied; exports include all filtered records regardless of the current page view.)
* How does the system handle report access by a Patient role? (Insurance verification report is staff-only; Patient role receives HTTP 403.)
