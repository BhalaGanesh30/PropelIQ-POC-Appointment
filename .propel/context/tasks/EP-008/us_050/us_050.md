# User Story - US_050

## Story ID
* ID: US_050

## Story Title
* CPT and E/M Mapping Suggestions

## Description
* As a clinician, I want CPT and Evaluation & Management (E/M) code suggestions with explainable rationale so that I can efficiently select and validate procedure codes for billing.

## Acceptance Criteria
1. **Given** a patient's clinical profile and appointment details are available, **When** I request CPT/E/M suggestions, **Then** the system returns ranked CPT codes and an E/M level suggestion with confidence scores and rationale within 2.5 seconds p95.
2. **Given** CPT suggestions are displayed, **When** I view a suggestion card, **Then** the CPT code, description, confidence score, rationale text, and a link to supporting clinical evidence are all visible.
3. **Given** an E/M level suggestion is provided, **When** I view the E/M mapping, **Then** the suggested E/M level (e.g., 99213) is explained with the contributing clinical complexity factors.
4. **Given** the AI model confidence for CPT is below threshold, **When** suggestions are returned, **Then** a "Manual coding recommended" indicator is shown with the low-confidence flag.

## Edge Cases
* What happens if the appointment type is not mappable to a CPT code? (System returns a "No CPT suggestion available for this appointment type" message and offers the code search workflow.)
* How does the system handle CPT code deprecations? (CPT code database is updated on a defined schedule; deprecated codes are excluded from suggestions; an alert is raised if the active database is older than 90 days.)
