# User Story - US_040

## Story ID
* ID: US_040

## Story Title
* Document Upload with Malware Scanning

## Description
* As a patient or staff member, I want to upload clinical documents (PDF, JPG, PNG, TIFF) up to 10 MB with automatic malware scanning so that only safe, validated files enter the system.

## Acceptance Criteria
1. **Given** I am authenticated, **When** I select and submit a file for upload, **Then** the system validates the file type (PDF, JPG, PNG, TIFF) and size (max 10 MB) before accepting the file.
2. **Given** a valid file is submitted, **When** the malware scan is executed, **Then** the scan completes before the file is persisted and a clean file is stored in encrypted cloud storage (Cloudflare R2).
3. **Given** the malware scan detects a threat, **When** the scan result is returned, **Then** the file is rejected, not persisted, the upload response returns an error message, and the event is logged for security review.
4. **Given** a file type not in the approved list is submitted, **When** the type validation runs, **Then** the API returns HTTP 400 with a message listing the accepted file types.

## Edge Cases
* What happens if the malware scanner is unavailable? (Upload is queued in a pending scan state; file is not accessible until scan completes; user is notified of the delayed scan.)
* How does the system handle a file that exceeds 10 MB? (HTTP 400 is returned immediately with "File exceeds the maximum allowed size of 10 MB"; no partial upload occurs.)
