# User Story - US_052

## Story ID
* ID: US_052

## Story Title
* Code Search with Autocomplete and Favorites

## Description
* As a clinician, I want to search ICD-10 and CPT codes by keyword or code number with autocomplete and save favorites so that I can quickly find and reuse frequently used codes without relying solely on AI suggestions.

## Acceptance Criteria
1. **Given** I am in the coding workflow, **When** I type at least 2 characters in the code search field, **Then** an autocomplete dropdown appears with matching codes (by code number or description keyword) within 500 ms.
2. **Given** search results are displayed, **When** I click on a code, **Then** the code is selected as my coding decision and added to the current encounter's coding record.
3. **Given** I want to save a frequently used code, **When** I click the "Favorite" star icon on a code result, **Then** the code is added to my personal favorites list and appears at the top of future search results.
4. **Given** I remove a code from favorites, **When** I click the "Unfavorite" icon, **Then** the code is removed from my favorites list and the change is persisted immediately.

## Edge Cases
* What happens if the code search returns no results? (An empty state is shown: "No codes found for your search term. Try a different keyword or code number.")
* How does the system handle deprecated or inactive codes in search results? (Deprecated codes are filtered from results by default; an "Include inactive codes" toggle allows advanced users to view them.)
