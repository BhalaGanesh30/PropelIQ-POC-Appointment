# User Story - US_042

## Story ID
* ID: US_042

## Story Title
* In-Browser Document Viewer

## Description
* As a clinician or staff member, I want to view uploaded clinical documents in the browser with zoom, rotate, and full-text search so that I can review documents without downloading them.

## Acceptance Criteria
1. **Given** I navigate to a patient's documents, **When** I click on a completed document, **Then** the document renders in an embedded browser viewer within 3 seconds.
2. **Given** the document viewer is open, **When** I use the zoom controls (in/out), **Then** the document scales smoothly between 50% and 200% zoom levels.
3. **Given** the document viewer is open, **When** I use the rotate control, **Then** the document rotates 90 degrees clockwise per click.
4. **Given** OCR extraction is available for the document, **When** I type a search term in the full-text search field, **Then** matching text occurrences are highlighted in the document and I can navigate between them using next/previous controls.

## Edge Cases
* What happens if a document has no OCR text available (e.g., still processing)? (Full-text search is disabled with a message "Text extraction in progress"; zoom and rotate remain functional.)
* How does the system handle large multi-page documents? (Lazy-loading renders pages progressively; the viewer shows a page count and a navigation control for jumping to specific pages.)
