# User Story - US_025

## Story ID
* ID: US_025

## Story Title
* Appointment History with Filters and Export

## Description
* As a patient, I want to view my appointment history with date and status filters and export it as a PDF so that I can keep records of my healthcare visits.

## Acceptance Criteria
1. **Given** I am authenticated as a patient, **When** I navigate to "My Appointments," **Then** a list of all my past and upcoming appointments is displayed sorted by date descending with status labels.
2. **Given** the appointment history is displayed, **When** I apply a status filter (e.g., Completed, Cancelled, No-Show), **Then** the list updates within 500 ms to show only appointments matching the filter.
3. **Given** I apply a date range filter, **When** the filter is applied, **Then** only appointments within the specified date range are shown.
4. **Given** I click "Export PDF," **When** the export is processed, **Then** a PDF containing my filtered appointment history downloads within 5 seconds.

## Edge Cases
* What happens if a patient has hundreds of appointments? (Pagination is applied with 20 records per page; the export PDF includes all filtered records regardless of pagination.)
* How does the system handle an empty appointment history? (An empty state message is displayed: "No appointments found. Book your first appointment.")
