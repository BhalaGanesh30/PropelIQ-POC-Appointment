# User Story - US_033

## Story ID
* ID: US_033

## Story Title
* Walk-In Creation and Patient Registration Conversion

## Description
* As a staff member, I want to create walk-in appointment entries and convert walk-in patients to registered accounts so that unscheduled patients are tracked in the queue and can later access the full platform.

## Acceptance Criteria
1. **Given** a patient walks in without a prior appointment, **When** I create a walk-in entry with the patient's name and visit reason, **Then** a temporary walk-in record is created and inserted into the queue with an estimated wait-time position.
2. **Given** a walk-in record exists, **When** I initiate patient registration for the walk-in, **Then** a new patient account is created and the walk-in record is associated with the new patient profile.
3. **Given** a walk-in is inserted into the queue, **When** the queue dashboard refreshes, **Then** the walk-in appears with a "Walk-In" label distinguishing them from scheduled patients.
4. **Given** an existing registered patient walks in, **When** I search by name or phone number, **Then** their existing patient profile is found and the walk-in appointment is created directly against their account without duplicating the profile.

## Edge Cases
* What happens if the same name is searched and returns multiple patients? (A disambiguation list is shown with patient demographics to identify the correct record.)
* How does the system handle walk-ins when the clinic is at maximum capacity? (Staff are notified of capacity; walk-in creation is still allowed with a visual capacity warning.)
