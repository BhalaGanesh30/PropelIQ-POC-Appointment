# Task - TASK_001

## Requirement Reference

- User Story: us_027
- Story Location: .propel/context/tasks/EP-003/us_027/us_027.md
- Acceptance Criteria:
  - AC-1: Given a reminder event is dispatched, When the patient's preferred channel is email, Then a formatted reminder email is sent via SendGrid containing appointment details, a one-click confirm button, and a one-click cancel link.
  - AC-2: Given a reminder event is dispatched, When the patient's preferred channel is SMS, Then a concise reminder SMS is sent via Twilio containing appointment time and a short-link for confirmation or cancellation.
  - AC-4: Given a reminder delivery fails (provider error or unreachable), When the failure is detected, Then the system retries up to 3 times with exponential backoff and moves the event to a dead-letter queue after all retries fail.
- Edge Cases:
  - How does the system handle Twilio SMS rate limiting? Messages are queued and dispatched within provider rate limits; urgent same-day reminders are prioritized.

## Task Overview

Implement the concrete `IEmailService` and `ISmsService` providers (defined in US_026 task_002) using SendGrid and Twilio SDKs. The `SendGridEmailService` (AC-1) sends formatted HTML reminder emails containing appointment details (date, time, provider, location), a one-click confirm button, and a one-click cancel link — both backed by HMAC-signed token URLs generated by `IReminderTokenService` (created in task_002 of this story). The `TwilioSmsService` (AC-2) sends concise SMS messages containing appointment time and a shortened confirmation/cancellation URL. Both providers integrate with the existing `NotificationDispatcher` from US_026 task_002, which already handles the Polly retry pipeline (Decision 6: exponential backoff). This task enhances the retry-exhaustion path (AC-4) by introducing a `DeadLetterEvent` entity and `IDeadLetterRepository` — when `ReminderDispatchWorker` marks a reminder as `Failed` after 3 retries, a `DeadLetterEvent` record is persisted with the original payload and failure reason for manual review or re-processing. For Twilio rate limiting (edge case), the `TwilioSmsService` implements a `SemaphoreSlim`-based concurrency gate configured from `TwilioOptions.MaxConcurrentSends` and catches `TooManyRequestsException` to signal the dispatcher for retry. Same-day reminders (2-hour offset) are dispatched with higher priority by the existing `ReminderDispatchWorker` ordering (`ORDER BY ScheduledAt ASC`). API keys for SendGrid and Twilio are stored in configuration (via `IOptions<SendGridOptions>` and `IOptions<TwilioOptions>`) and must never be logged or exposed — aligned with NFR-007 (encryption) and OWASP credential management.

// server/src/PropelIQ.Infrastructure/Reminders/
//   SendGridEmailService.cs
namespace PropelIQ.Infrastructure.Reminders;

public sealed class SendGridEmailService : IEmailService
{
    private readonly ISendGridClient _client;
    private readonly SendGridOptions _options;
    private readonly IReminderTokenService _tokenService;
    private readonly IAppointmentRepository _appointmentRepo;
    private readonly ILogger<SendGridEmailService> _logger;

    public SendGridEmailService(
        ISendGridClient client,
        IOptions<SendGridOptions> options,
        IReminderTokenService tokenService,
        IAppointmentRepository appointmentRepo,
        ILogger<SendGridEmailService> logger)
    {
        _client = client;
        _options = options.Value;
        _tokenService = tokenService;
        _appointmentRepo = appointmentRepo;
        _logger = logger;
    }

    // AC-1: Formatted email with confirm + cancel links
    public async Task SendReminderAsync(
        ReminderEvent reminder,
        CancellationToken ct = default)
    {
        var appointment = await _appointmentRepo
            .GetByIdAsync(reminder.AppointmentId, ct)
            ?? throw new InvalidOperationException(
                $"Appointment {reminder.AppointmentId} not found");

        var confirmUrl = _tokenService.GenerateConfirmUrl(
            reminder.AppointmentId, reminder.ReminderId);
        var cancelUrl = _tokenService.GenerateCancelUrl(
            reminder.AppointmentId, reminder.ReminderId);

        var from = new EmailAddress(
            _options.FromAddress, _options.FromName);
        var to = new EmailAddress(appointment.PatientEmail);
        var subject =
            $"Appointment Reminder - " +
            $"{appointment.AppointmentDate:MMMM dd, yyyy}";

        var htmlContent = BuildReminderHtml(
            appointment, confirmUrl, cancelUrl);
        var plainContent = BuildReminderPlainText(
            appointment, confirmUrl, cancelUrl);

        var msg = MailHelper.CreateSingleEmail(
            from, to, subject, plainContent, htmlContent);

        var response = await _client.SendEmailAsync(msg, ct);

        if (!response.IsSuccessStatusCode)
        {
            var body = await response.Body
                .ReadAsStringAsync(ct);
            _logger.LogWarning(
                "SendGrid returned {Status}: {Body}",
                response.StatusCode, body);
            throw new HttpRequestException(
                $"SendGrid error: {response.StatusCode}");
        }
    }

    private static string BuildReminderHtml(
        Appointment appt,
        string confirmUrl,
        string cancelUrl)
    {
        return $"""
        <div style="font-family:sans-serif;max-width:600px;
                    margin:0 auto;padding:24px;">
          <h2>Appointment Reminder</h2>
          <p>You have an upcoming appointment:</p>
          <table style="border-collapse:collapse;width:100%;">
            <tr>
              <td style="padding:8px;font-weight:bold;">Date</td>
              <td style="padding:8px;">
                {appt.AppointmentDate:dddd, MMMM dd, yyyy}</td>
            </tr>
            <tr>
              <td style="padding:8px;font-weight:bold;">Time</td>
              <td style="padding:8px;">
                {appt.AppointmentDate:hh:mm tt}</td>
            </tr>
            <tr>
              <td style="padding:8px;font-weight:bold;">
                Provider</td>
              <td style="padding:8px;">
                {appt.ProviderName ?? "TBD"}</td>
            </tr>
            <tr>
              <td style="padding:8px;font-weight:bold;">
                Location</td>
              <td style="padding:8px;">
                {appt.Location ?? "TBD"}</td>
            </tr>
          </table>
          <div style="margin-top:24px;text-align:center;">
            <a href="{confirmUrl}"
               style="display:inline-block;padding:12px 32px;
                      background:#4CAF50;color:#fff;
                      text-decoration:none;border-radius:4px;
                      margin-right:16px;">
              Confirm Appointment</a>
            <a href="{cancelUrl}"
               style="display:inline-block;padding:12px 32px;
                      background:#f44336;color:#fff;
                      text-decoration:none;border-radius:4px;">
              Cancel Appointment</a>
          </div>
          <p style="margin-top:24px;font-size:12px;color:#666;">
            If you did not request this reminder,
            please ignore this email.</p>
        </div>
        """;
    }

    private static string BuildReminderPlainText(
        Appointment appt,
        string confirmUrl,
        string cancelUrl)
    {
        return $"""
        Appointment Reminder

        Date: {appt.AppointmentDate:dddd, MMMM dd, yyyy}
        Time: {appt.AppointmentDate:hh:mm tt}
        Provider: {appt.ProviderName ?? "TBD"}
        Location: {appt.Location ?? "TBD"}

        Confirm: {confirmUrl}
        Cancel: {cancelUrl}
        """;
    }
}

```csharp
// server/src/PropelIQ.Infrastructure/Reminders/
//   TwilioSmsService.cs
namespace PropelIQ.Infrastructure.Reminders;

public sealed class TwilioSmsService : ISmsService, IDisposable
{
    private readonly ITwilioRestClient _client;
    private readonly TwilioOptions _options;
    private readonly IReminderTokenService _tokenService;
    private readonly IAppointmentRepository _appointmentRepo;
    private readonly SemaphoreSlim _concurrencyGate;
    private readonly ILogger<TwilioSmsService> _logger;

    public TwilioSmsService(
        ITwilioRestClient client,
        IOptions<TwilioOptions> options,
        IReminderTokenService tokenService,
        IAppointmentRepository appointmentRepo,
        ILogger<TwilioSmsService> logger)
    {
        _client = client;
        _options = options.Value;
        _tokenService = tokenService;
        _appointmentRepo = appointmentRepo;
        _logger = logger;
        // Edge case: Rate limiting via concurrency gate
        _concurrencyGate = new SemaphoreSlim(
            _options.MaxConcurrentSends);
    }

    // AC-2: Concise SMS with short-link
    public async Task SendReminderAsync(
        ReminderEvent reminder,
        CancellationToken ct = default)
    {
        await _concurrencyGate.WaitAsync(ct);
        try
        {
            var appointment = await _appointmentRepo
                .GetByIdAsync(reminder.AppointmentId, ct)
                ?? throw new InvalidOperationException(
                    $"Appointment {reminder.AppointmentId} " +
                    "not found");

            var actionUrl = _tokenService.GenerateActionUrl(
                reminder.AppointmentId, reminder.ReminderId);

            var body =
                $"Reminder: Appointment on " +
                $"{appointment.AppointmentDate:MMM dd} at " +
                $"{appointment.AppointmentDate:hh:mm tt}. " +
                $"Confirm or cancel: {actionUrl}";

            var message = await MessageResource.CreateAsync(
                to: new PhoneNumber(appointment.PatientPhone),
                from: new PhoneNumber(_options.FromNumber),
                body: body,
                client: _client);

            if (message.ErrorCode is not null)
            {
                _logger.LogWarning(
                    "Twilio error {Code}: {Msg}",
                    message.ErrorCode, message.ErrorMessage);
                throw new HttpRequestException(
                    $"Twilio error: {message.ErrorCode}");
            }
        }
        catch (ApiException ex)
            when (ex.Status == 429)
        {
            // Edge case: Twilio rate limiting
            _logger.LogWarning(
                "Twilio rate limited for reminder {Id}",
                reminder.ReminderId);
            throw new HttpRequestException(
                "Twilio rate limited", ex);
        }
        finally
        {
            _concurrencyGate.Release();
        }
    }

    public void Dispose() => _concurrencyGate.Dispose();
}
```
